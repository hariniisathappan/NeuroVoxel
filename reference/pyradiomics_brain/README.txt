Test data of the PyRadiomics project (https://github.com/AIM-Harvard/pyradiomics, folder "data"): two brain MRI test cases (brain1, brain2)
with their label files, and the project's official baseline feature values (baseline_*.csv). PyRadiomics is released under a 3-clause BSD licence
(PYRADIOMICS_LICENSE.txt). NeuroVoxel uses these files only for the verification tab: it runs the installed PyRadiomics on the same cases and
compares with the official baseline values, using the project's own acceptance limit (3 %).
